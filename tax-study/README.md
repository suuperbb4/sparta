# 세무사 동차 학습실

2027년 세무사 1·2차 동차 대비 학습 앱 (1차 선택: 행정소송법).

- 앱: https://claude.ai/artifact/YYbnWkS5y8jQP7ARdtBjgg
- `index.html`: 앱 화면 (문제 풀기, OX, 오답노트, 암기노트, 분석·출제경향)

## 실제 기출 (신뢰도 기준)
- 원본: 큐넷(Q-Net) 공개 1차 문제지 제60~63회(2023~2026), A형. 공공누리 제1유형
- 정답: 큐넷 최종정답 → `data/answers.py`
- 문항은 원본 PDF를 잘라낸 이미지(`img/연도/과목-번호.png`)로 보여 준다 (텍스트 변환 오류 방지)
- `tools/build_gichul.py`: 문항 분류(단원, 말/계산), 기출 보기 → OX 추출, 출제경향 집계 → `data/gichul/*.json`
- OX 판정 근거: "옳지 않은 것" 문제의 정답 보기 = X, 나머지 = O / "옳은 것" 문제는 반대 / "모두 고른 것"은 정답 조합으로 판정
- 회계 OX는 4개년 말문제 2회 이상 출제 단원만 포함
- 2026년 이미지는 아티팩트 파일 수 한도(511) 때문에 asset 저장소에 올림 → `data/asset_map.txt`

## AI 예상 문제
- `data/build.py`: AI가 만든 예상 문제·암기카드. 앱에 "AI 예상 · 검증 전"으로 표시
- 세법 수치는 2026년 시행 법령 기준. 2027년 시험 전에 2026년 세법개정을 반영해야 함
