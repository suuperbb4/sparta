# 세무사 동차 학습실

2027년 세무사 1·2차 동차 대비 학습 앱 (1차 선택: 행정소송법).

- 앱: https://claude.ai/artifact/YYbnWkS5y8jQP7ARdtBjgg
- `index.html`: 앱 화면 (문제 풀기, 오답노트, 암기노트, 분석)
- `data/build.py`: 문제은행·암기카드 원본. 실행하면 `data/qsets/*.json`, `data/notes/*.json`을 생성
- 풀이 기록은 앱 데이터베이스의 사용자 개인 영역(`data/users/<id>/study/attempts`)에 저장

세법 수치는 2026년 시행 법령 기준이며, 2027년 시험 전에 2026년 세법개정 내용을 반영해야 한다.
