# 시중 문제집 PDF → 세무사 동차 학습실 "내 문제집" 가져오기 (로컬 세션용 작업 지시문)

아래 내용을 회원님 컴퓨터의 Claude Code 세션(작업 폴더: 세무사책)에 그대로 붙여넣는다.

---

이 폴더에 있는 세무사 시험 문제집 PDF들을 내 학습 앱 "세무사 동차 학습실"에 넣어줘.
앱: https://claude.ai/artifact/YYbnWkS5y8jQP7ARdtBjgg (내 소유, 비공개)

## 목표
문제집의 1차 객관식(5지선다) 문제를 문항 단위 원본 이미지 + 정답 + (있으면) 해설로 앱 데이터베이스에 넣는다.
문제 텍스트를 옮겨 적지 말고 원본 이미지로 넣는다(옮겨 적기 오류 방지). 2차 서술형·계산형 세트 문제는 이번에는 건너뛰고 목록만 보고한다.

## 순서
1. 폴더의 PDF 목록을 보여주고, 각 PDF가 어떤 책·과목인지(재정학/세법학개론/회계학개론/행정소송법), 텍스트 PDF인지 스캔본인지, 문제·정답·해설이 어디(쪽)에 있는지 파악해서 먼저 나에게 보고하고 확인을 받는다. 확인 전에는 앱에 아무것도 쓰지 않는다.
2. 한 권에서 한 단원(20~40문항)만 먼저 처리해서 결과를 보여주고, 내가 괜찮다고 하면 나머지를 진행한다.
3. 문항 자르기: 텍스트 PDF면 문항 번호 위치(좌표)로, 스캔본이면 페이지 이미지에서 문항 경계를 찾아 자른다. 필요하면 Python의 PyMuPDF(pip install pymupdf)와 Pillow를 쓴다.
   - 이미지는 흑백, 폭 800~1100px, PNG. 한 문항이 두 쪽에 걸치면 이어 붙인다.
   - 자른 결과를 몇 개 직접 열어 보고 문항이 잘리거나 다른 문항이 섞이지 않았는지 확인한다.
4. 정답: 책의 정답표·해설에서 문항별 정답(1~5)을 뽑는다. 복수 정답은 [2,4], 전항 정답은 "A". 정답을 못 찾은 문항은 넣지 말고 목록으로 보고한다.
5. 해설: 책에 해설이 있으면 해당 문항 해설 텍스트를 그대로 exp에 넣는다(요약하거나 지어내지 않는다). 없으면 exp를 비운다.
6. 이미지 업로드: Artifact 도구의 asset 업로드(publish, url=앱 주소, asset=true, file_paths 최대 25개씩)로 올리고, 결과로 받은 url("/_blob/…")을 그대로 쓴다.
7. 데이터 쓰기: ArtifactData 도구로 아래 형식의 문서를 컬렉션 "qsets"에 새로 만든다(batch, 한 번에 50개 이하).
   - 문서 id: book-<책코드>-<과목코드>-<순번>  예) book-kim2026-segae-01  (문서 하나에 40문항 이하, 256KB 이하)
   - 기존 문서(g로 시작, ox, notes, meta, 그 밖에 이미 있는 qsets 문서)는 절대 수정·삭제하지 않는다.

## 문서 형식
```json
{
  "subject": "segae",
  "book": "책 이름 (저자, 판)",
  "questions": [
    {
      "id": "b-kim2026-segae-0001",
      "type": "gichul",
      "origin": "book",
      "topic": "소득세법",
      "kind": "말",
      "diff": 2,
      "src": "책 이름 p.123 문5",
      "ans": 3,
      "img": ["/_blob/<업로드 결과 url의 id>"],
      "exp": "책 해설 원문 (없으면 빈 문자열)"
    }
  ]
}
```
- subject: 재정학 jae, 세법학개론 segae, 회계학개론 hoegae, 행정소송법 haeng
- topic: 세법학개론은 국세기본법/국세징수법/소득세법/법인세법/부가가치세법/조세범처벌법/국제조세조정법 중 하나. 회계학개론은 단원명(재고자산, 금융상품, 수익, 원가관리 등). 행소법·재정학은 책의 장 제목.
- kind: 보기가 금액·수치인 계산문제는 "계산", 나머지는 "말".
- 책에 실린 실제 기출 문제라면 src에 "(제○회 기출)"을 덧붙인다.

## 마무리 보고
처리한 책·과목별 문항 수, 정답을 못 찾아 뺀 문항, 이미지 자르기가 의심스러운 문항, 건너뛴 2차 문제 목록을 표로 보고한다.

## 주의
- 책 내용은 저작물이므로 GitHub나 다른 곳에 올리지 않는다. 앱(비공개)과 이 컴퓨터에만 둔다.
- Artifact/ArtifactData 도구가 이 세션에 없으면 앱에 쓰지 말고, 위 형식의 JSON과 PNG를 "세무사책/_학습실_업로드" 폴더에 저장한 뒤 그 사실만 보고한다.
