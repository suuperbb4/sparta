- 원칙: 참는 것이 아니라 환경을 바꾼다. 유튜브는 지우지 않는다(주말·나들이 보상으로 유지).

## 교재 회독 관리

- 하루 최소 = (목표 회독 − 현재 회독 + 1) × 총량 − 진행 ÷ 마감까지 공부일(일요일 제외).
- 목차 사진을 받으면 총량과 chapters를 `books` 문서에 채운다. 원가 2차 연습서, 재정학·행소법 기출 교재는 이름을 받으면 추가한다.
- 아침 루틴: 오일풀링, 따뜻한 소금물, 올리브오일, 영양제. 15분 안에 끝내고 바로 열품타 측정.

## 세무회계연습 10회독 계획 (2026-11-16 확정 제안)

- 범위: 법인 1~14장(178), 소득 1~6장(68), 부가 1~4장(52) = 298문제. 법인 15~17장, 소득 7~9장은 제외. 회독 순서 부가 → 법인 → 소득.
- 11/16 현재: 5회독, 부가 끝·법인 6장(감가상각비)까지 = 116/298. 소득은 4회독까지 끝난 상태.
- 단계: 5회독 전체 298 → 6회독 유예 제외 258 → 7~10회독 [1차] 표시 111 + 틀린 문제.
- 남은 양 884문제 ÷ 138 공부일 = 하루 7문제. 예상 완료: 5회독 12/15, 6회독 1/27, 7회독 2/15, 8회독 3/5, 9회독 3/24, 10회독 4/12.
- 전체 10회독(1,672문제, 하루 12문제)은 아침 블록으로 불가능해서 단계식으로 바꿈. 2차 표시 문제는 1차 직후 다시 돌린다.
