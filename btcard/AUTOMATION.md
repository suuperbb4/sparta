# 비티 노트 자동 발행 연결 현황

모든 자동화는 같은 스크립트 하나로 올립니다.

```
bash scripts/btnote-publish.sh 발행일 시리즈 이미지폴더_또는_파일목록 [캡션파일]
```

- 시리즈: `morning`(모닝 인사이트) · `market`(마켓) · `world`(5분 세상읽기) · `weekly`(주간 비티, 앱에서는 5분 세상읽기 분류)
- 이미지·캡션만 커밋하면 GitHub Actions가 1~2분 안에 미리보기와 목록을 만들어 앱에 나타납니다.
- 실행하는 곳에 이 저장소(`suuperbb4/sparta`, 브랜치 `claude/youthful-hopper-tkvfr8`)를 받을 수 있고 푸시 권한이 있어야 합니다.

| 콘텐츠 | 만드는 곳 | 연결 상태 |
|---|---|---|
| 마켓 3장 | 클라우드 예약 작업 "Market 2" (평일 07:00) | **연결됨.** 8단계에서 텔레그램 전송 뒤 앱에 올림 |
| 주간 비티 | 클라우드 예약 작업 "주간 비티 최종 (토)" | 프롬프트에 6) 추가 필요 (그 대화에서만 수정 가능) |
| 5분 세상읽기 | 사용자 PC의 로컬 세션 "비티의 5분 세상읽기_사전작업" | 그 세션 지시문에 한 단락 추가 필요 |
| 모닝 인사이트 9장 | 원고는 클라우드, **이미지는 NAS**가 렌더 | NAS(n8n) 승인 단계에 실행 노드 추가 필요 → `N8N.md` |

## 주의

- 지금은 텔레그램 승인과 상관없이 생성 직후 앱에 올라갑니다(시범 운영). 반려한 카드는 발행 도구(`admin.html`)에서 같은 날짜·시리즈로 다시 올리거나 GitHub에서 폴더를 지우면 됩니다.
- 주간 비티는 캔바에서 손본 최종본이 아니라 자동 렌더본(preview)이 올라갑니다.
