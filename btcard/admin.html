매일 카드 올리는 방법

  1. GitHub 저장소에서 btcard/cards/날짜/시리즈/ 폴더에 이미지를 올려요. 예: btcard/cards/2026-11-28/morning/01.png
  2. 시리즈 폴더 이름은 morning(모닝 인사이트), world(5분 세상읽기), market(비티의 마켓)이에요.
  3. 파일 이름은 01, 02, 03… 순서대로. 올리면 1~2분 뒤 앱에 자동으로 나타나요.
