# 비티 카드 시범판

네이버 인사이트 노트 구독자가 매일 카드뉴스를 앱처럼 보는 웹앱(PWA)입니다. 서버 없이 GitHub Pages로 운영할 수 있게 만든 **시범판**입니다.

## 구독자 입장 방식

1. 네이버 유료 글 맨 아래 버튼에 `https://주소/btcard/?k=이번주코드` 링크를 겁니다.
2. 구독자가 버튼을 누르면 35일 동안 열리고, 누를 때마다 다시 35일로 연장됩니다.
3. 홈 화면에 추가한 앱에서는 처음 한 번 연동 코드를 직접 입력합니다. 아이폰은 홈 화면 앱과 브라우저가 저장 공간을 따로 쓰기 때문입니다.

## 매주 할 일: 연동 코드 바꾸기

1. `btcard/admin.html`을 열어 새 코드를 만듭니다.
2. 나온 한 줄을 `btcard/config.json`의 `keys`에 추가합니다. 지난주 줄은 남기고 2주 전 줄은 지웁니다.
3. 네이버 유료 글 버튼 링크와 하단의 코드 문구를 새 것으로 바꿉니다.

## 매일 할 일: 카드 올리기

- 위치: `btcard/cards/날짜/시리즈/01.png` (예: `btcard/cards/2026-11-28/market/01.jpg`). 같은 폴더에 `text.txt`를 두면 카드 뒤에 "비티의 한마디"로 나옵니다.
- 시리즈 폴더: `morning` 모닝 인사이트, `market` 비티의 마켓, `world` 5분 세상읽기, `weekly` 주간 비티
- 텔레그램 승인과 연결하는 방법은 `N8N.md`를 보세요.
- 올리면 GitHub Actions가 `feed.json`을 자동으로 갱신합니다. 직접 갱신하려면 `node scripts/build-feed.mjs`.
- `cards/2026-11-26`, `cards/2026-11-27`은 샘플이므로 실제 운영 전에 지웁니다.

## 시범판의 한계

- 카드 이미지 주소를 아는 사람은 코드 없이도 이미지를 볼 수 있습니다. 진짜 차단은 서버 버전에서 합니다.
- 푸시 알림, 네이버 로그인, 기기 관리, 4,900원 결제는 서버 버전에서 추가합니다.
