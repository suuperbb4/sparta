# 비티 노트 시범판

네이버 인사이트 노트 구독자가 매일 카드뉴스를 앱처럼 보는 웹앱(PWA)입니다. 서버 없이 GitHub Pages로 운영할 수 있게 만든 **시범판**입니다.

## 구독자 입장 방식

1. 네이버 유료 글 맨 아래 버튼에 `https://주소/btcard/?k=이번주코드` 링크를 겁니다.
2. 구독자가 버튼을 누르면 35일 동안 열리고, 누를 때마다 다시 35일로 연장됩니다.
3. 홈 화면에 추가한 앱에서는 처음 한 번 연동 코드를 직접 입력합니다. 아이폰은 홈 화면 앱과 브라우저가 저장 공간을 따로 쓰기 때문입니다.

## 운영: 발행 도구 (`admin.html`)

폰이나 PC에서 `https://suuperbb4.github.io/sparta/btcard/admin.html`을 엽니다. 처음 한 번 **설정** 탭에 GitHub 토큰을 저장하면, 그다음부터는 아래만 하면 됩니다.

- **카드**: 발행일·시리즈 선택 → 이미지 여러 장 선택(파일 이름 순, ‹ › 로 순서 조정) → 캡션 붙여 넣기 → 발행하기. 같은 날짜·시리즈로 다시 올리면 덮어씁니다.
- **공지**: 제목·내용 → 올리기. "맨 위에 고정"을 켜면 오늘 화면에도 띠로 나옵니다.
- **연동 코드**: 새 코드 만들기 → 적용하기 → 나온 링크를 네이버 유료 글 버튼에 연결.

발행은 커밋 하나로 이미지·캡션(`text.txt`)·`feed.json`을 함께 올리므로 1~2분 뒤 앱에 바로 반영됩니다.

## 분류

`config.json`의 `categories`(모닝 인사이트·마켓·5분 세상읽기·기타)와 `series`의 `cat`으로 묶습니다. 주간 비티(`weekly`)와 특집(`etc`)은 "기타"에 들어갑니다.

## 시범판의 한계

- 카드 이미지 주소를 아는 사람은 코드 없이도 이미지를 볼 수 있습니다. 진짜 차단은 서버 버전에서 합니다.
- 푸시 알림, 네이버 로그인, 기기 관리, 4,900원 결제는 서버 버전에서 추가합니다.
